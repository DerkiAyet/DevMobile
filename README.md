# Flutter Learning Playground

A collection of small Flutter projects, reusable widgets, and notes that I built while learning Flutter. Everything lives in a single app: the home screen has a button for each project, so you can switch between them and compare how each concept is implemented.

> This repo is a learning journal.

## Projects

| # | Project | What it covers |
|---|---|---|
| 1 | **To-Do App** | Managing a task list: adding, completing and deleting items, and handling app state |
| 2 | **E-commerce App** | A shopping app UI: product listing, cart and navigation between screens |
| 3 | **Light vs Dark Mode** | Switching between light and dark themes |
| 4 | **Responsive Design** | Adapting layouts to different screen sizes and orientations |

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install)
- An editor such as VS Code or Android Studio
- An emulator or a physical device

### Run the app

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/<your-repo>.git

# 2. Move into the project
cd <your-repo>

# 3. Install dependencies
flutter pub get

# 4. Run the app
flutter run
```

## Adding a New Project

1. Create a new folder in `lib/Projects/` using the next number, for example `5_My_New_Project`.
2. Build the project's entry screen inside that folder.
3. Add a button for it in `main.dart`.
