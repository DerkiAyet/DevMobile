1. CustomScrollView
  It’s basically a scrollable container that accepts slivers instead of regular widgets.

2. What is a Sliver?
  - A sliver is just a scrollable portion of the screen.
  - You can mix and match multiple slivers to create custom scrolling effects.
  - Slivers = building blocks for scrollable areas.

3. Types of Slivers:
  - SliverAppBar → a scrollable app bar that can expand, collapse, and stay pinned.
    -> Example:
          CustomScrollView(
            slivers: [
              SliverAppBar(
                title: Text("SliverAppBar Example"),
                backgroundColor: Colors.deepPurple,
                expandedHeight: 200, // height when expanded
                pinned: true,  // stays visible at the top when scrolling
                floating: false, // true = shows when you scroll up a little
                flexibleSpace: FlexibleSpaceBar(
                  background: Image.network(
                    "https://picsum.photos/800/400",
                    fit: BoxFit.cover,
                  ),
                ),
              ),
              SliverList(
                delegate: SliverChildBuilderDelegate(
                  (context, index) => ListTile(title: Text("Item $index")),
                  childCount: 20,
                ),
              ),
            ],
          )

  - SliverList → like ListView, but as a sliver.
    -> Example:
          CustomScrollView(
            slivers: [
              SliverList(
                delegate: SliverChildBuilderDelegate(
                  (context, index) {
                    return Container(
                      height: 80,
                      margin: EdgeInsets.all(8),
                      color: Colors.deepPurple[100 * ((index % 8) + 1)],
                      child: Center(child: Text("Item $index")),
                    );
                  },
                  childCount: 15, // total number of children
                ),
              ),
            ],
          )

  - SliverGrid → like GridView, but as a sliver.
    -> Example:
          CustomScrollView(
            slivers: [
              SliverGrid(
                delegate: SliverChildBuilderDelegate(
                  (context, index) => Container(
                    alignment: Alignment.center,
                    color: Colors.deepPurple[100 * ((index % 8) + 1)],
                    child: Text("Grid $index"),
                  ),
                  childCount: 12,
                ),
                gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
                  crossAxisCount: 3,     // number of columns
                  mainAxisSpacing: 10,   // spacing between rows
                  crossAxisSpacing: 10,  // spacing between columns
                  childAspectRatio: 1,   // width/height ratio
                ),
              ),
            ],
          )

  - SliverToBoxAdapter → allows you to insert a normal widget (e.g. a Container) inside a sliver scroll.
    -> Example:
          CustomScrollView(
            slivers: [
              SliverToBoxAdapter(
                child: Container(
                  height: 150,
                  color: Colors.deepPurple,
                  child: Center(
                    child: Text(
                      "I’m a normal widget",
                      style: TextStyle(color: Colors.white, fontSize: 20),
                    ),
                  ),
                ),
              ),
              SliverList(
                delegate: SliverChildBuilderDelegate(
                  (context, index) => ListTile(title: Text("Item $index")),
                  childCount: 10,
                ),
              ),
            ],
          )

  - SliverPadding → add padding around slivers.
    -> Example:
          CustomScrollView(
            slivers: [
              SliverPadding(
                padding: EdgeInsets.all(16), // padding outside the sliver
                sliver: SliverGrid(
                  delegate: SliverChildBuilderDelegate(
                    (context, index) => Container(
                      color: Colors.deepPurple[100 * ((index % 8) + 1)],
                      child: Center(child: Text("Item $index")),
                    ),
                    childCount: 8,
                  ),
                  gridDelegate: SliverGridDelegateWithFixedCrossAxisCount(
                    crossAxisCount: 2,
                    mainAxisSpacing: 10,
                    crossAxisSpacing: 10,
                  ),
                ),
              ),
            ],
          )
